# Tape avec moi — instructions pour les agents

Application d'apprentissage de la dactylographie pour enfants. React + TypeScript
au client, Hono + Drizzle + PostgreSQL au serveur, déployée par Coolify.

## Agent skills

### Issue tracker

Issues GitHub sur `vlebourl/dactymalin` (dépôt **public**), via la CLI `gh`.
See `docs/agents/issue-tracker.md`.

### Triage labels

Les cinq libellés canoniques, sans renommage. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context : `CONTEXT.md` et `docs/adr/` à la racine, créés paresseusement.
See `docs/agents/domain.md`.
